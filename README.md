# Musk‑Tweets

An offline‑first Python app that takes a tweet (as if posted by Elon Musk) and simulates four distinct personas using LoRA adapters on TinyLlama:

- CNN News Reporter → produces a news headline
- Reddit User → creates a meme title from the tweet and news headline
- Goldman Sachs Analyst → outputs a brief report title
- Market AI → predicts the next 5 days of prices using the tweet, news, analyst report, and current price

It renders a modern desktop UI with an intro screen, animated loading screen, and a results dashboard including a line chart and generated meme image.

> Note: While the core pipeline is designed to be offline (LoRA on a local TinyLlama), two optional online integrations are supported:
> - Live price lookup via yfinance
> - Meme image generation via Pollinations API

## Features

- Desktop UI (CustomTkinter) with smooth loading/transition states
- Role‑based generation (CNN, Reddit, Goldman, Market) via LoRA on TinyLlama (or fallback rule‑based generator to prototype fast)
- Meme image generation (Pollinations) with optional text caption overlay
- Live price fetch for TSLA/DOGE using yfinance (fallbacks when offline)
- 5‑day price prediction + Matplotlib chart
- Small sample dataset and utilities to expand with synthetic data
- Training scripts to fine‑tune LoRA adapters for each role

## Quickstart

1) Python
- Recommended: Python 3.10–3.12
- 3.13 works but some ML libs may lag behind; if you hit build issues, prefer 3.10/3.11.

2) Create a virtual environment
```
# Windows (PowerShell)
python -m venv .venv
.venv\Scripts\Activate.ps1

# macOS/Linux
python -m venv .venv
source .venv/bin/activate
```

3) Install dependencies
```
pip install -r requirements.txt
```

4) (Optional) Set Pollinations API key
- Only needed if you want real image generation instead of the fallback text image.
```
# Windows (PowerShell)
$env:POLLINATIONS_API_KEY="YOUR_KEY"

# macOS/Linux
export POLLINATIONS_API_KEY="YOUR_KEY"
```

5) Run the app
```
python main.py
```

Type a tweet in the intro screen, click Analyze, watch the loading screen animate, then see the results: CNN headline, meme image/title, analyst report, price chart, and current price.
